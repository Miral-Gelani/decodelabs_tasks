# 🤖 Rule-Based AI Chatbot

A Rule-Based AI Chatbot developed using Python that responds to predefined user inputs through decision-making logic and continuous interaction.

---

## 📌 Project Overview

This chatbot simulates basic human conversation using conditional statements and predefined responses. It demonstrates fundamental Artificial Intelligence concepts through rule-based interaction.

---

## ✨ Features

- Greeting Responses
- AI & Machine Learning Information
- Time Display Feature
- Continuous Chat Interaction
- Exit Command Support
- User-Friendly Interface

---

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

---

## 💬 Sample Conversation

```text
You: hi
Bot: Hello! Welcome to AI ChatBot.

You: ai
Bot: AI stands for Artificial Intelligence.

You: machine learning
Bot: Machine Learning is a subset of AI.

You: bye
Bot: Thank you for using AI ChatBot. Goodbye!
```

- User Input Handling
- String Processing
- Basic AI Chatbot Development
