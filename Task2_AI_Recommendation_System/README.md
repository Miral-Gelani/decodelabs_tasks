# 🎬 AI Entertainment Recommendation System

A Python-based recommendation system that suggests movies, books, and music based on user preferences. The project uses rule-based matching logic to analyze user interests and provide relevant recommendations.

---

## 📌 Project Overview

The AI Entertainment Recommendation System is designed to demonstrate the core concept of recommendation engines. Users select a category and provide their preferences, after which the system matches those preferences with predefined data and generates personalized recommendations.

This project focuses on logic building, pattern matching, and user preference analysis.

---

## ✨ Features

* Personalized Recommendations
* Movie Recommendation Module
* Book Recommendation Module
* Music Recommendation Module
* User-Friendly Console Interface
* Rule-Based Matching Logic
* Fast and Lightweight Execution
